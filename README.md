# .github

Plataforma digital para gestão, organização e geração automatizada do Relatório de Atividades Docentes (RAD), com foco em processos de progressão funcional em universidades federais.

A plataforma centraliza atividades acadêmicas, documentos comprobatórios e cálculo de pontuação conforme baremas institucionais, permitindo ao docente acompanhar sua evolução e gerar relatórios completos prontos para submissão.
